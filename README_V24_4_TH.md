# Thai Flood Watch V24.4 — GPS Button Fix

แก้ไขปุ่ม “ตำแหน่งปัจจุบัน” ในแบบฟอร์มอัพภาพน้ำท่วมในพื้นที่

- เพิ่มตัวจัดการการกดปุ่ม GPS ซึ่งขาดไปจาก V24.3
- สำหรับแบบฟอร์มที่ฝังใน iframe ให้หน้าเว็บหลักเป็นผู้ขอสิทธิ์ตำแหน่ง แล้วส่งพิกัดกลับมา
- เติมละติจูด/ลองจิจูด และเลื่อนแผนที่ไปยังตำแหน่ง
- แสดงข้อผิดพลาดหากผู้ใช้ปฏิเสธสิทธิ์, GPS ไม่พร้อม หรือไม่ได้ใช้ HTTPS
- คงระบบ API และฟังก์ชันอื่นจาก V24.3

## ติดตั้ง
แตก ZIP แล้วอัปโหลดไฟล์เว็บไซต์ทั้งหมดแทนชุดเดิม (โดยเฉพาะ index.html และ flood-eye.html) จากนั้นเปิดผ่าน HTTPS และอนุญาตสิทธิ์ Location ในเบราว์เซอร์

หมายเหตุ: GPS แสดงตำแหน่งของอุปกรณ์ ไม่ได้ยืนยันว่าเป็นตำแหน่งน้ำท่วม โปรดตรวจสอบก่อนส่งรายงาน
